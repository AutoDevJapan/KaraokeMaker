# KaraokeMaker

<a name="できること"></a>

手元の音楽・動画から、自分のWindows PCで歌うための伴奏とカラオケ映像を作ります。歌詞の表示時間、キー、再生速度を調整できます。

カラオケ変換に使う音楽・動画・歌詞・生成物はPC内で扱います。初回は音源分離に必要な部品をダウンロードします。

- <a name="windowsで使う"></a>[Windows配布一覧](https://github.com/AutoDevJapan/KaraokeMaker/releases)から `KaraokeMaker-windows.zip` を入手できます。展開後は `START-HERE.md` にも導入手順があります。
- [公式Wiki](https://github.com/AutoDevJapan/KaraokeMaker/wiki)で導入と最初の1曲を案内します。<a name="歌詞の貼り付け方"></a>[歌詞と字幕](https://github.com/AutoDevJapan/KaraokeMaker/wiki/歌詞と字幕を調整する)、<a name="sunoで音楽を作る"></a>[音楽制作の連携](https://github.com/AutoDevJapan/KaraokeMaker/wiki/音楽制作の連携)、[音楽制作のロードマップ](docs/music-platform-roadmap.md)も確認できます。
- <a name="開発コマンドで使う"></a>[コマンドラインの使い方](https://github.com/AutoDevJapan/KaraokeMaker/wiki/コマンドラインで使う) · [開発と配布](https://github.com/AutoDevJapan/KaraokeMaker/wiki/開発と配布)
