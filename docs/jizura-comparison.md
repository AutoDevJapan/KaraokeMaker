# ADJ実曲とJIZURAの比較

2026-10-07。歌入りの文字演出はJIZURA、歌うための伴奏と字幕はKaraokeMakerを組み合わせる。JIZURAのランダム演出を、カラオケの読みやすさの代わりに使わない。

## 受け取った評価と確認範囲

[製品スレッド](https://discord.com/channels/1552944707464597524/1556258511975874614)の返信1556299925015371839（2026-10-04 22:40 JST）を実際に読み、「めっちゃいいね！ ちなみに、JIZURAは使わないの？」という肯定的な評価と比較の依頼を確認した。品質評価を未回答として扱わない。この返信は、商用公開や第三者素材の権利、全曲の同期誤差の承認とは読み替えない。

既存の本人曲2曲の記録は [mash-quality.md](mash-quality.md)、CC0曲4曲の記録は [adj-validation.md](adj-validation.md) に保持する。本人のメタル191.293秒は分離と4K出力111.109秒、ラップ113.425秒は69.249秒。全曲出力のWAVは48kHz/24bit/stereo、true peakは-3.1dBFS。28秒サンプル2本の字幕と分離品質に対する肯定的な返信を受領済み。これらの処理時間に、歌詞を手で確定する時間は含まれない。

## 比較方法と結果

ログイン済みの本人のChromeで [公式JIZURA](https://852wa.github.io/JIZURA/) v0.10.1を操作した。曲は以前に内部利用が許可された本人の「The Hope III - The Nothing」の30〜58秒。正本と元映像から照合済みの7行を使い、開始時刻0 / 0.40 / 3.90 / 9.20 / 13.70 / 19.00 / 21.50秒を保持した。24〜28秒は間奏。歌詞・音源・プロジェクトはGitへ入れない。

音源のファイル選択ではブラウザの許可要求が判断前に閉じられ、セキュリティ確認を完了できなかった。音源読み込み、拍検出、音源のブラウザ保存は未確認。保護設定を変更せず、音源は読み込まなかった。別の制作工程として、公式画面から無音映像を保存し、FFmpegでPC内の許可済み音源と合わせた。これはJIZURAの音源読み込み試験ではない。

| 最初の案、1080p/30fps・画質「高」 | 28.900 | 66,505,680 | 36秒 |
| 1行1カットへ調整した途中案、4K/30fps・画質「標準」 | 28.900 | 153,983,841 | 12秒 |

PCはRyzen 9 9950X3D / RTX 5090。解像度だけでなく演出数・画質設定も違うので、4Kの方が一般に速いという比較には使わない。3分曲の映像作成時間へ外挿しない。

最初の案は、長い英語行の回転・重なり・細かな切り替えで読みにくい箇所があった。最終比較案は各行を1カット・中央の横組みにし、グリッチ・色ズレ・フラッシュを切った。行時刻と出力LRCを照合し、2秒間隔のフレームで横組みと間奏の空表示を確認した。登場・退場のぼかしや文字の欠ける演出は残るので、歌うための常時読める字幕の代わりにしない。設定とシード、JIZURAプロジェクト、元のLRCとJIZURA出力LRCを保存した。

最終案はPC内で音源を合わせ、映像の余白だけを落として28.000秒にした。検品CLIで全編復号28.000秒、true peak -3.3dBTP、4K/H.264/yuv420p/30fps/AACの形式合格（終了0）を確認した。試聴・全編目視等の人手項目は未確認のまま記録する。確認用の720p動画は6,729,032 bytes。納品版の4K映像を720pに差し替えるものではない。

## 互換性と同期の注意点

- JIZURAの「文字整列」は見た目だけの設定ではない。公式ソースの `typeset` は文字を0.2秒先に出す。実画面でもオン時に2行目が0.20秒、オフ時に0.40秒へ変わることを確認した。同期基準を保つ最終案はオフにし、レイアウトを各行で指定する。設定変更後は画面の行時刻・保存LRC・映像をそれぞれ照合する。
- KaraokeMakerの空LRC行 `[00:24.00]` は歌詞を消す命令。JIZURAへの作業コピーでは `[00:24.00][間奏 4]` とした。JIZURAの出力LRCにもこの記法が残るので、そのままKaraokeMakerへ戻すと記法自体が歌詞として表示される。戻すときは空の時刻行へ戻し、元の正本は変更しない。
- `/`、`*`、末尾の `!`、`|` はJIZURAで演出記法になる。文字通りの歌詞と演出命令を混同しない。音節単位の同期を合格済みとは扱わない。
- 音源なしでは今回0.9秒の余白が付いた。歌を合わせる際は、歌詞が24秒で終わり間奏が28秒まであることを確認し、映像だけの余白を落として28秒へそろえる。音源・曲構成は切らない。長さの差と音声の有無を `inspect-delivery` で検査する。
- 比較用の歌入り音源は元のtrue peak +0.7dBFSだった。PC内で単純に4dB下げてAAC化した途中案は-3.3dBFS。原本のSHA-256は `dad397c0545220006e0b55b461ba840d2cd698a8a89878dfb48f01bd8fa0efc8` のまま。マスタリングや音源の置き換えではない。正式納品の音量は顧客と合意して検品する。

## 制作サービスへの取り込み

初期の出品案は3分まで20,000円、横1080pの歌入り文字動画とカラオケ動画、提供伴奏のWAV/MP3、行字幕、修正1回。4Kは両動画を変更して+8,000円。初期は完成伴奏を提供できる自作曲に限定し、文字・配色・構成の調整を含める。JIZURAは歌入り版の演出に使い、歌う練習用の字幕はKaraokeMakerで作る。画面案と短い動画を先に合意する。第三者が作ったビートや音源も、本人の曲というだけで公開許可済みにしない。

手作業4〜6時間は見積りであり、全制作の実測ではない。今回測れたのは自動処理と短いJIZURA出力。実曲の正式歌詞の全編照合、ヘッドホンとスピーカーの全編試聴、3分曲を受付から納品まで通す手作業時間は未完了。公開サンプルの権利とこれらの検品が済んでから受注を始める。分離が必要な曲は曲ごとの比較試聴を条件に、実績を積んで受付範囲を広げる。
