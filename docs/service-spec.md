## 商品と価格案

| --- | --- | --- |
| 基本セット | 20,000円 | 1曲180秒まで。歌入りの歌詞動画、伴奏音源、伴奏の歌詞動画、行単位の字幕、修正1回 |
| 曲の延長 | +5,000円 / 開始した60秒 | 181〜240秒は25,000円、241〜300秒は30,000円。初期受付は最大5分 |
| 縦動画を追加 | +5,000円 | 同じ曲の1080×1920版2本。縦用の改行と余白を調整 |

| 横4Kへ変更 | +8,000円 | 歌入り・伴奏の2本を3840×2160で納品。1440p追加と重ねて課金しない |

基本セットだけで完成品を納品する。必須オプションを設定しない。横1920×1080・30fpsを標準とし、横1440p・横4Kは任意の追加料金とする。縦を希望する場合は購入前に横1080pからの差し替え（追加料金なし）か両方の納品（有料）を決める。縦は1080×1920で、縦4Kは初期メニューに含めない。初期は同時受注2曲まで。特急、作詞・作曲、ボーカル収録、音声の複製、ミックス・マスタリング、音節ごとの同期は提供しない。低解像度の持込画像・動画の細部は4Kへ拡大しても復元されないが、文字は4Kで直接描画する。

通常サービスの販売手数料は22%。基本価格20,000円から4,400円が引かれ、15,600円が残る。購入者側は5.5%で、20,000円の場合は21,100円が支払いの目安となる。これは表示価格が購入時の課税分を含む場合の例で、振込費・税・経費を引く前。アカウントの課税設定と決済画面で最終金額を確認する。オプションにも手数料がかかる。[販売の公式案内](https://coconala.com/pages/guide_sell)、[購入手数料の公式案内](https://coconala.com/smartphone/pages/guide_payment)

目標の手作業は3分曲で4〜6時間（受付30分、分離・試聴45分、字幕90分、画面調整45分、全編検品30分、修正・納品60分）。6時間なら手数料差引後は時間あたり2,600円。実績値ではない。最初の3件の実時間を記録し、6時間を超える曲が続く場合は受付条件や価格を改める。追加素材購入・追加課金は行わない。

## 出品方法とココナラの確認事項

動画制作を主とした「動画・アニメーション・撮影」のMV制作に合うカテゴリで、テキスト・データ納品の通常サービスを1件出す。動画を納品するサービスでも、ビデオチャット形式にはしない。カテゴリの現行名称・最低価格・選べる価格を公開操作時に確認する。同じセットを音楽カテゴリへ重複出品しない。[提供形式・重複出品・価格の規則](https://help.coconala.com/hc/ja/articles/9517522720409)

連絡、権利の合意、決済、試作品・完成品の添付はココナラ内で行う。Discordやメール、外部購入ページへ顧客を誘導しない。ココナラで得た顧客情報を営業・他用途に転用しない。複数アカウントの所持が禁止されているため、既存アカウントの有無を確認してから公開する。[ルールとマナー](https://coconala.com/pages/guide_rule)

大きな4K動画は、トークルームの添付容量（公式案内では200MB、購入前メッセージは100MB）を超える場合がある。納品前に実容量を確認する。ZIPで収まらなければ、分割ZIPによる添付か、公式が容量超過時に許容するギガファイル便でのファイル受け渡しを購入前に顧客と合意する。連絡と決済はココナラ内に保ち、Google Drive等の連絡可能な共有先を使わない。ZIPでMP4が大きく縮むと期待しない。4Kの解像度を下げて納品を済ませない。[公式の容量・外部受け渡しの例外](https://help.coconala.com/hc/ja/articles/218180658)

他人の曲の無許可のカラオケ化、商用不可の素材、無許可のキャラクター・写真・ロゴは受け付けない。AI生成イラストは、動画の一部に使う場合も禁止対象なので顧客の持ち込みを含め使用しない。音源分離AIについては、この公式ページに明示的な個別許可があるわけではない。禁止対象のイラスト生成と区別し、作業内容を正直に記載して出品基準を再確認する。[知的財産権とAI素材の公式基準](https://help.coconala.com/hc/ja/articles/9517379139097)

成人向け、差別・誹謗中傷、権利侵害、違法行為、運営が禁止する政治関連動画等の依頼は受け付けない。再生数・収益や完全な歌声除去を保証しない。無期限の修正、返金保証という宣伝、架空の実績は掲げない。[禁止サービス一覧](https://help.coconala.com/hc/ja/articles/9517249749017)

まずココナラで3件の制作時間と品質を測る。他市場への出品はその後に、各市場の現行規約・手数料を確認して別途判断する。今回、他市場への登録・誘導や出品は行わない。

## 受注前の確認票

購入前のメッセージで以下を確認し、回答・証拠・最終合意をトークルームに残す。本人確認書類やアカウントのパスワードを求めない。

- 曲名、活動名、秒単位の曲長、希望日、公開先・収益化・配信用途、クレジットの表記。
- 作曲・作詞の権利者。共同作者、所属事務所、音楽出版社、著作権管理事業者への委託の有無と、今回の加工・歌詞表示・納品・商用公開の許可。自作しただけで全ての権利を保持していると扱わない。
- 録音された音源の権利者と、歌唱・演奏の使用同意。委託作曲、購入したビート、サンプル、共演者の声が含まれる場合は、商用動画化・音源加工を許す契約や許諾文面を確認する。音声の複製・なりすましは受け付けない。
- 歌入り完成音源と、あれば元の伴奏・ステム。WAV/FLACを優先し、44.1/48kHz・16/24bit・ステレオを推奨。MP3/M4Aも相談可能だが、失われた音は戻せない。ファイルは1GB以下、サービス上限は5分。
- 正式な歌詞全文、読み方、繰り返し、改行、歌い始めと間奏。顧客の歌詞を正本とし、ASR候補で書き換えない。
- 持ち込む画像・動画・VTuber立ち絵・ロゴの作者と商用加工・動画公開の許可。フリー素材なら配布元・ライセンス・取得日と必要クレジット。AI生成イラストは使用しない。
- 横/縦、背景色、歌詞の強調色、文字の雰囲気、顔を避けたい範囲、伴奏にコーラスを残すか。参考は方向を説明するために使い、他者の動画をコピーしない。
- 納品形式・字幕同梱・修正範囲・価格・期限、素材の保存期間、実績掲載は別許可であること。

購入前に返してもらう宣言の例:

> 提供する曲・歌詞・録音・歌唱や演奏・画像について、私は権利を保有しているか、今回の有料制作、音源の分離・加工、歌詞の動画表示、納品後の予定用途を許す許諾を得ています。共同作者・所属先・管理事業者・素材ライセンスによる制限を伝えます。無許可の第三者素材やAI生成イラストは含めません。制作と納品に必要な範囲で素材の複製・加工を許可します。実績公開の可否は別途回答します。

宣言だけで疑義を解消したことにしない。範囲が分からない許諾は確認する。購入前に権利と分離試聴を確認できない曲は契約しない。購入後に問題が判明した場合は作業を止め、理由を伝え、ココナラの手続きに従ってキャンセルを相談する。

## 納品物と使用範囲

| 納品物 | 形式 |
| --- | --- |
| 歌入りの歌詞動画 | MP4 / H.264 / yuv420p / 1920×1080 / 30fps / AAC 256kbps |
| カラオケ歌詞動画 | 同上、承認された伴奏を使用 |
| 伴奏 | WAV / PCM24bit / 44.1kHz / ステレオ、およびMP3 / 320kbps |
| 修正用字幕 | UTF-8のLRC、SRT、ASS。LRCは原曲時刻、SRT/ASSは出力時刻 |

1440p/4Kオプションは両方の動画の解像度を変更する。ビットレートは映像内容に応じて変わり、字幕の描画解像度は動画の解像度と一致する。書き出し時間・容量の測定と設定は [4k-validation.md](4k-validation.md) に残す。

48kHz指定や特殊な形式は事前見積りで確認する。現行のアプリ出力は44.1kHz。元音源・歌詞・キャラクターの権利は顧客に残る。当方が作る動画部分は顧客の活動での商用配信・公開・編集を許可する。ソフトウェア、汎用テンプレート、フォント、第三者素材の著作権を譲渡するものではない。テンプレートの共通構造は他案件でも使用するが、顧客の曲・文字・画像は流用しない。著作権譲渡や再販売の希望は購入前に調整する。[使用範囲の合意方法](https://help.coconala.com/hc/ja/articles/218273168-)

制作素材はPC内で処理し、外部AI・Sunoへ送らない。顧客へ納品するためのココナラ添付は受注時に合意した範囲で担当者が行う。アプリからの自動投稿・公開は追加しない。GitHubやDiscordに顧客素材を置かない。アプリの原本削除に備えて顧客の受領素材は別の案件フォルダに保持し、正式納品後30日で受領コピー・中間物・納品コピーを削除する。本人のPCやココナラ側の保存を消せるとは案内しない。

## 納期・修正・確認

素材・権利・分離試聴・構成・入金がそろった翌営業日から数える。平日を営業日とし、初稿5営業日以内、修正内容がそろってから最終版2営業日以内。初期は最終版まで7営業日を目安とする。顧客の確認待ちや素材差し替えは日程を再合意する。急ぎは受け付けない。

修正1回は、初稿から5営業日以内に歌詞の誤り・時刻・配色・文字位置の変更点をまとめて送ってもらう1往復。依頼を受けてから指摘を小出しに追加する場合は次の回とする。当方が正本と違う歌詞や不正な出力を作った場合の直しは無料回数に含めず、合意した納品内容まで直す。曲・音源の差し替え、新しい構成や全面作り直しは追加見積りと期限を合意してから行う。

初稿は通常メッセージで送り、修正後に「正式な納品」を行う。独自の修正1回とココナラの正式納品の差し戻し機能を混同しない。正式納品は相手の確認を待ち、勝手に取引を終了しない。[公式の納品・差し戻し案内](https://coconala.com/pages/guide_buy)

## 公開前にそろえるサンプル

自作または商用加工・実績公開まで書面で許可された曲で、30〜45秒の歌入り/伴奏比較と歌詞動画を作る。曲・詞・録音・声・絵の許可を全て残す。自作の色と文字の背景を使い、歌手向けとVTuber向けで2配色、横と縦の表示を見せる。分離の限界も聞ける比較にする。CC0等でも配布元・対象音源・歌詞・権利範囲を確認し、「自作」と偽らない。未完成のサンプルやテスト用の正弦波を制作実績にしない。

実績掲載の同意は基本契約と分け、曲名・表示名・使用区間・掲載先・未公開曲の解禁日を確認する。拒否による追加料金はない。第三者の声や顧客の未公開音源は許可なく出さない。公開・アカウント承認後も、サンプルの全編検品と権利確認が済んでから受注を開始する。

制作の具体的手順と残る開発項目は [production-workflow.md](production-workflow.md) を参照。
