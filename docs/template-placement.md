# タイトル・字幕の位置と手動回避領域

[テンプレートの基本設定](templates.md)に、任意の `placement` を追加する。顔の位置などを矩形で手動指定できる。顔の自動検出・自動配置は行わず、指定位置を勝手に変更しない。

```json
"placement": {
  "title": { "x": 0.2, "y": 0.15, "width": 0.6, "height": 0.15 },
  "subtitles": { "x": 0.2, "y": 0.6, "width": 0.6, "height": 0.2 },
  "avoid": [
    { "x": 0.3, "y": 0.35, "width": 0.4, "height": 0.2 }
  ]
}
```

これはテンプレートJSONの一項目であり、単独のJSONファイルではない。`x` と `y` は画面左上からの割合、`width` と `height` は画面全体に対する割合。有限な0〜1の範囲で、幅と高さを正にし、矩形全体を画面内に収める。タイトルと字幕は別の枠で、回避領域は複数指定できる。旧テンプレートはこの項目を省略でき、従来の配置になる。

タイトルは枠内の上中央、字幕は枠内の下中央に配置する。行数と実フォントで描画した高さを検査し、収まらない場合は出力を拒否する。フォントサイズを小さくしたり、枠を自動で動かしたりはしない。

保存時には矩形の範囲と、タイトル・字幕・回避領域同士の重なりを検査する。向き・解像度・素材に依存する次の検査は、実際の出力時に行う。

- 枠が保存余白と組込みのプラットフォーム安全領域の内側にあること。
- タイトル・字幕の実描画が指定枠に収まること。
- スケール後の実ロゴ矩形がタイトルや回避領域と重ならないこと。

正規化座標を画素へ変換するときは、左・上を切り上げ、右・下を切り捨てて指定枠の内側に収める。同じ画素座標で配置と安全領域を比較する。ロゴも回避の対象で、重なれば「ロゴ枠が回避領域と重なります」と拒否する。エラー時は枠・余白・使用素材を利用者が調整する。

ロゴは字幕の左右枠を含む安全領域の右上に置く。画像の縦横比を保ち、その領域の幅の25%・画面高の10%の両方に収める。衝突検査は上限の仮想矩形ではなく、実画像を縮小した寸法を使う。

`placement` は横縦共通の一組。同じ割合でも、向きによってプラットフォーム安全領域や文字幅が変わる。両方で有効と仮定せず、それぞれ出力・検品する。異なる配置が必要なら、同じプロジェクトの別テンプレートファイルに保存する。
